# Objectives

• Provide students with knowledge of the fundamentals of machine vision and image processing.
<font color="#95b3d7">• 使学生掌握机器视觉和图像处理的基础知识。</font>

• Provide students with knowledge of advanced computer vision algorithms and techniques.
<font color="#95b3d7">• 使学生掌握高级计算机视觉算法与技术。</font>

• Train students to apply machine vision and intelligence to develop real-world applications.
<font color="#95b3d7">• 训练学生运用机器视觉与智能技术开发现实应用。</font>

# Intended Learning Outcomes

Upon completion of the subject, students will be able to:
<font color="#95b3d7">完成本课程后，学生将能够：</font>

a) Understand fundamental concepts of machine vision and image processing techniques.
<font color="#95b3d7">a）理解机器视觉与图像处理技术的基本概念。</font>

b) Implement advanced computer vision algorithms for visual recognition tasks such as classification and detection.
<font color="#95b3d7">b）实现用于分类、检测等视觉识别任务的高级计算机视觉算法。</font>

c) Address real-world challenges using machine vision applications across various domains; and
<font color="#95b3d7">c）运用不同领域的机器视觉应用应对现实挑战；以及</font>

d) Critically assess and strengthen skills for integrating machine learning methods with machine vision to develop intelligent systems.
<font color="#95b3d7">d）批判性地评估并强化将机器学习方法与机器视觉相结合以开发智能系统的能力。</font>

# Subject Synopsis/Indicative Syllabus

1. Image Acquisition and Representation
<font color="#95b3d7">1. 图像采集与表示</font>

Image acquisition, cameral models, perspective projection; image representation, color fundamentals, RGB, CMYK, HSL/HSV color models; video representations.
<font color="#95b3d7">图像采集、相机模型、透视投影；图像表示、色彩基础、RGB、CMYK、HSL/HSV 颜色模型；视频表示。</font>

2. Image Processing Techniques
<font color="#95b3d7">2. 图像处理技术</font>

Image filters, linear/non-linear filters, convolutional filters; edge detection, image gradient, Sobel filter, Canny edge detector, Hough transform; local invariant features, corner detection, Harris corner detector, blob detection, Laplacian of Gaussian, SIFT detector and features, image matching, image stitching, image mosaicking.
<font color="#95b3d7">图像滤波器、线性或非线性滤波器、卷积滤波器；边缘检测、图像梯度、Sobel 滤波器、Canny 边缘检测器、霍夫变换；局部不变特征、角点检测、Harris 角点检测器、斑点检测、高斯拉普拉斯、SIFT 检测器与特征、图像匹配、图像拼接和图像镶嵌。</font>

3. Machine Learning for Vision
<font color="#95b3d7">3. 面向视觉的机器学习</font>

Supervised learning, classical statistical learning, cross validation; unsupervised learning, clustering algorithms, self-supervised learning, pre-training and fine-tuning, transfer learning; deep learning architectures, multi-layer perceptrons (MLP), convolutional neural networks (CNNs), UNet, vision transformer (ViT); back propagation, (stochastic) gradient descent; regularization, overfitting, underfitting.
<font color="#95b3d7">监督学习、经典统计学习、交叉验证；无监督学习、聚类算法、自监督学习、预训练与微调、迁移学习；深度学习架构、多层感知机（MLP）、卷积神经网络（CNN）、UNet、视觉 Transformer（ViT）；反向传播、随机梯度下降；正则化、过拟合与欠拟合。</font>

4. Visual Recognition Tasks and Algorithms
<font color="#95b3d7">4. 视觉识别任务与算法</font>

Semantic segmentation, classic segmentation methods (e.g., mean shift), foundation segmentation models (e.g.,SAM); object detection, region proposal, R-CNN series, YOLO series; instance segmentation; object tracking, optical flow, tracking by detection, multi-object tracking; multimodal learning, contrastive language-Image pre-training (CLIP), cross-modal image retrieval, image captioning, visual question answering, vision-language models (VLMs); image generation, generative adversarial network (GAN), diffusion models.
<font color="#95b3d7">语义分割、经典分割方法（例如均值漂移）、基础分割模型（例如 SAM）；目标检测、区域候选、R-CNN 系列、YOLO 系列；实例分割；目标跟踪、光流、基于检测的跟踪、多目标跟踪；多模态学习、对比式语言-图像预训练（CLIP）、跨模态图像检索、图像描述、视觉问答、视觉语言模型（VLM）；图像生成、生成对抗网络（GAN）、扩散模型。</font>

5. Advanced Topics in Vision and Intelligence
<font color="#95b3d7">5. 视觉与智能高级专题</font>

Multimodal large language models (MLLMs); 3D vision and depth perception, vision in robotics and autonomous systems; reinforcement learning in vision systems; ethical considerations and challenges in machine vision.
<font color="#95b3d7">多模态大语言模型（MLLM）；三维视觉与深度感知、机器人和自主系统中的视觉；视觉系统中的强化学习；机器视觉的伦理考量与挑战。</font>

# Teaching/Learning Methodology

The course material will be delivered as a combination of lectures, tutorials, and small group projects. Students will get familiar with basic concepts and technologies of visual data processing, representations and applications.
<font color="#95b3d7">课程材料将通过课堂讲授、导修课和小组项目相结合的方式讲授。学生将熟悉视觉数据处理、表示和应用的基本概念与技术。</font>
