# Objectives

The objectives of this subject are:
<font color="#95b3d7">本课程的目标是：</font>

1. apply data structures, searching and sorting algorithms in developing computer programs;
<font color="#95b3d7">1. 在开发计算机程序时应用数据结构、搜索算法和排序算法；</font>

2. use a database for efficient data storage and retrieval;
<font color="#95b3d7">2. 使用数据库高效地存储和检索数据；</font>

3. explore efficient data processing in distributed environments.
<font color="#95b3d7">3. 探索分布式环境中的高效数据处理。</font>

# Intended Learning Outcomes

Upon completion of the subject, students will be able to:
<font color="#95b3d7">完成本课程后，学生将能够：</font>

a. demonstrate a comprehensive understanding of data structures, searching and sorting algorithms;
<font color="#95b3d7">a. 全面理解数据结构、搜索算法和排序算法；</font>

b. use databases properly in real-life problems and apply optimization techniques to enhance query performance;
<font color="#95b3d7">b. 在现实问题中正确使用数据库，并运用优化技术提升查询性能；</font>

c. apply the techniques for distributed database design and query processing in real-life problems.
<font color="#95b3d7">c. 将分布式数据库设计与查询处理技术应用于现实问题。</font>

# Subject Synopsis/Indicative Syllabus

1. Introduction to Data Structures
<font color="#95b3d7">1. 数据结构导论</font>

• Data structures: stack, queue, linked-list, heap, tree.
<font color="#95b3d7">• 数据结构：栈、队列、链表、堆、树。</font>

2. Efficient Data Processing in Computer Programs
<font color="#95b3d7">2. 计算机程序中的高效数据处理</font>

• Searching algorithms: linear search, binary search;
<font color="#95b3d7">• 搜索算法：线性搜索、二分搜索；</font>

• Sorting algorithms: bubble sort, insertion sort, selection sort, quick sort, merge sort, heap sort;
<font color="#95b3d7">• 排序算法：冒泡排序、插入排序、选择排序、快速排序、归并排序、堆排序；</font>

• Big-O notation and time complexity analysis.
<font color="#95b3d7">• 大 O 表示法与时间复杂度分析。</font>

3. Introduction to Databases
<font color="#95b3d7">3. 数据库导论</font>

• Relational model; relational algebra; SQL; integrity constraints.
<font color="#95b3d7">• 关系模型；关系代数；SQL；完整性约束。</font>

4. Efficient Data Processing in Databases
<font color="#95b3d7">4. 数据库中的高效数据处理</font>

• File organization; indexing; view materialization and maintenance;
<font color="#95b3d7">• 文件组织；索引；视图物化与维护；</font>

• Query processing and optimization;
<font color="#95b3d7">• 查询处理与优化；</font>

• Transaction management and concurrency control; two-phase locking protocol.
<font color="#95b3d7">• 事务管理与并发控制；两阶段锁协议。</font>

5. Introduction to Distributed Databases
<font color="#95b3d7">5. 分布式数据库导论</font>

• DDB architecture; DDB design: data fragmentation; data allocation; data replication; consistency issues.
<font color="#95b3d7">• 分布式数据库架构；分布式数据库设计：数据分片、数据分配、数据复制和一致性问题。</font>

6. Efficient Data Processing in Distributed Databases
<font color="#95b3d7">6. 分布式数据库中的高效数据处理</font>

• DDB query processing and optimization; query decomposition; data localization; join strategies in DDB;
<font color="#95b3d7">• 分布式数据库的查询处理与优化；查询分解；数据本地化；分布式数据库中的连接策略；</font>

• DDB transaction management and concurrency control; two-phase commit protocol.
<font color="#95b3d7">• 分布式数据库的事务管理与并发控制；两阶段提交协议。</font>

# Teaching/Learning Methodology

This subject emphasizes the technical aspects of data structures and practical aspects of database systems. It is intended to equip students with knowledge and experience on solving real-life problems by using data structures, centralized databases, and distributed databases.
<font color="#95b3d7">本课程强调数据结构的技术层面和数据库系统的实践层面，旨在使学生获得运用数据结构、集中式数据库和分布式数据库解决现实问题的知识与经验。</font>

The lectures will be used to deliver course materials.
<font color="#95b3d7">课堂讲授用于讲解课程材料。</font>

Labs and tutorials will be used to practice exercises.
<font color="#95b3d7">实验课和导修课用于开展练习。</font>
