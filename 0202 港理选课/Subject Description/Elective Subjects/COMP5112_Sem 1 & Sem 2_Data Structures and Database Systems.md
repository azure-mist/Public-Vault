# Objectives

The objectives of this subject are to:
<font color="#95b3d7">本课程的目标是：</font>

1. apply data structures, sorting and searching algorithms in developing computer programs;
<font color="#95b3d7">1. 在开发计算机程序时应用数据结构、排序算法和搜索算法；</font>

2. use and administrate a database system properly.
<font color="#95b3d7">2. 正确使用和管理数据库系统。</font>

# Intended Learning Outcomes

Upon completion of the subject, students will be able to:
<font color="#95b3d7">完成本课程后，学生将能够：</font>

a. demonstrate a comprehensive understanding of data structures, sorting and searching algorithms;
<font color="#95b3d7">a. 全面理解数据结构、排序算法和搜索算法；</font>

b. apply database systems and the associated tools in real-life problems;
<font color="#95b3d7">b. 将数据库系统及相关工具应用于现实问题；</font>

c. apply the principles and practices of good database design and analysis in real-life problems, leveraging emerging technologies for global challenges.
<font color="#95b3d7">c. 将良好的数据库设计与分析原则和实践应用于现实问题，并利用新兴技术应对全球性挑战。</font>

# Subject Synopsis/Indicative Syllabus

1. Data structures: representation and algorithms
<font color="#95b3d7">1. 数据结构：表示与算法</font>

Linear structures: linked-lists, stacks, queues; tree structures: binary trees, balanced trees, tree traversals; other common data structures: priority queues, heaps.
<font color="#95b3d7">线性结构：链表、栈、队列；树结构：二叉树、平衡树、树遍历；其他常见数据结构：优先队列、堆。</font>

2. Sorting and searching algorithms
<font color="#95b3d7">2. 排序与搜索算法</font>

Common sorting algorithms: bubble sort, insertion sort, selection sort, quick sort, merge sort, heap sort.
<font color="#95b3d7">常用排序算法：冒泡排序、插入排序、选择排序、快速排序、归并排序、堆排序。</font>

3. Basic concepts of database system
<font color="#95b3d7">3. 数据库系统的基本概念</font>

Database and its applications; DBMS design objectives and its components; data independence.
<font color="#95b3d7">数据库及其应用；数据库管理系统的设计目标及组成部分；数据独立性。</font>

4. Relational data model
<font color="#95b3d7">4. 关系数据模型</font>

Relational structure; relational algebra; SQL; relational constraints.
<font color="#95b3d7">关系结构；关系代数；SQL；关系约束。</font>

5. Database design
<font color="#95b3d7">5. 数据库设计</font>

Entity-relationship model; functional dependencies; normalization.
<font color="#95b3d7">实体关系模型；函数依赖；规范化。</font>

6. Data storage and querying
<font color="#95b3d7">6. 数据存储与查询</font>

File organization; indexing and hashing; query processing.
<font color="#95b3d7">文件组织；索引与散列；查询处理。</font>

# Teaching/Learning Methodology

This subject emphasizes the technical aspects of data structures and practical aspects of database systems. It is intended to equip the student with knowledge and experience on solving real-life problems by using data structures and database systems.
<font color="#95b3d7">本课程强调数据结构的技术层面和数据库系统的实践层面，旨在使学生获得运用数据结构和数据库系统解决现实问题的知识与经验。</font>

The lectures will be used to deliver course material.
<font color="#95b3d7">课堂讲授用于讲解课程材料。</font>

Labs and tutorials will be used to practice exercises.
<font color="#95b3d7">实验课和导修课用于开展练习。</font>
