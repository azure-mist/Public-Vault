# Objectives

To equip students with a fundamental understanding of Cyber and Internet security and practical skills of handling Cyber and Internet security issues.
<font color="#95b3d7">使学生基本理解网络空间与互联网安全，并掌握处理相关安全问题的实践技能。</font>

Students will be equipped to:
<font color="#95b3d7">学生将能够：</font>

1. describe the concepts and principles of Cyber and Internet security;
<font color="#95b3d7">1. 描述网络空间与互联网安全的概念和原理；</font>

2. explain the attack surface at different network layers;
<font color="#95b3d7">2. 解释不同网络层的攻击面；</font>

3. understand the security mechanisms in major TCP/IP protocols;
<font color="#95b3d7">3. 理解主要 TCP/IP 协议中的安全机制；</font>

4. develop practical skills to analyze network traffic for dissecting the attacks exploiting TCP/IP protocols and designing defense mechanisms;
<font color="#95b3d7">4. 培养分析网络流量的实践技能，以剖析利用 TCP/IP 协议的攻击并设计防御机制；</font>

5. understand the major threats to web applications;
<font color="#95b3d7">5. 理解 Web 应用面临的主要威胁；</font>

6. analyze the attacks targeting on web applications and design defense mechanisms;
<font color="#95b3d7">6. 分析针对 Web 应用的攻击并设计防御机制；</font>

7. develop practical skills to conduct penetration testing and set up network firewall/IDS/IPS;
<font color="#95b3d7">7. 培养开展渗透测试以及配置网络防火墙、IDS 和 IPS 的实践技能；</font>

8. understand the major threats to systems (e.g., PC, smartphone, etc.)
<font color="#95b3d7">8. 理解个人电脑、智能手机等系统面临的主要威胁。</font>

# Intended Learning Outcomes

Upon completion of the subject, students will be able to:
<font color="#95b3d7">完成本课程后，学生将能够：</font>

a) understand and apply fundamental cyber security concepts as well as advanced and specialized cyber security knowledge for formulating models and solutions.
<font color="#95b3d7">a）理解并应用网络安全基础概念以及高级专业知识，以构建模型和解决方案。</font>

b) analyse and solve cyber security problems through critical thinking, analytical thinking and creative thinking.
<font color="#95b3d7">b）运用批判性思考、分析性思考和创造性思考分析并解决网络安全问题。</font>

c) design and evaluate systems/applications to satisfy user needs and various requirements (e.g., detect attack, discover vulnerability, set up defense mechanisms, etc.).
<font color="#95b3d7">c）设计和评估系统或应用，以满足用户需求和各种要求（例如检测攻击、发现漏洞、建立防御机制等）。</font>

d) dealing with complex ethical and professional issues.
<font color="#95b3d7">d）处理复杂的伦理与专业问题。</font>

e) demonstrating leadership and qualities of reflective practitioners.
<font color="#95b3d7">e）展现领导能力和反思型实践者的素质。</font>

# Subject Synopsis/Indicative Syllabus

1. Principle of Cyber Security and Privacy.
<font color="#95b3d7">1. 网络安全与隐私原理。</font>

2. Attack surface at different network layers, including MAC, IP, TCP, Application layers.
<font color="#95b3d7">2. 不同网络层的攻击面，包括 MAC、IP、TCP 和应用层。</font>

3. Security mechanisms in TCP/IP protocols, including IP Security, Internet Key Exchange, routing security, SSL/TLS, and TCP security
<font color="#95b3d7">3. TCP/IP 协议中的安全机制，包括 IP 安全、互联网密钥交换、路由安全、SSL/TLS 和 TCP 安全。</font>

4. Traffic analysis for analyzing the attacks.
<font color="#95b3d7">4. 用于分析攻击的流量分析。</font>

5. Web security and major threats to web applications.
<font color="#95b3d7">5. Web 安全与 Web 应用面临的主要威胁。</font>

6. Network intrusion detection and prevention, firewalls, penetration testing.
<font color="#95b3d7">6. 网络入侵检测与防御、防火墙、渗透测试。</font>

7. Threats to systems (e.g., PC, smartphone, etc.)
<font color="#95b3d7">7. 个人电脑、智能手机等系统面临的威胁。</font>

8. Professionalism and legal/social issues (e.g., security certification)
<font color="#95b3d7">8. 专业素养及法律和社会问题（例如安全认证）。</font>

# Teaching/Learning Methodology

The course will be delivered as a combination of lectures, tutorials, labs, workshops, and class project. The course will emphasize on both the principles and practices of Cyber and Internet Security. The principles will be covered mainly through the lectures and the tutorials, whereas the practice aspects will be taught through labs and workshops. The class project will help students reinforce what they have learnt, including both principles and practical skills.
<font color="#95b3d7">本课程结合课堂讲授、导修课、实验课、工作坊和课堂项目开展，并同时强调网络空间与互联网安全的原理和实践。原理主要通过课堂讲授和导修课介绍，实践内容则通过实验课与工作坊讲授。课堂项目将帮助学生巩固所学的原理和实践技能。</font>
